# Curva Fabric

Curva Fabric 是面向服装品牌、制衣厂、面料贸易商和产品开发团队的牛仔布 B2B 独立站。网站以面料选型、布样申请、技术参数沟通和多品质 RFQ 为核心转化，不提供面向消费者的成衣零售结账。

## 核心业务

- 硬挺牛仔布：中磅、重磅、原色及工装类组织
- 弹力牛仔布：舒适弹力、高回复及商业化牛仔裤用布
- 轻薄牛仔布：衬衫、连衣裙、半裙和轻型下装用布
- 特色面料：黑色、本白、再生棉及定制开发
- 技术支持：成分、oz/GSM、组织、门幅、弹力、缩率、纬斜、色牢度
- 订单支持：布样、洗水测试、MOQ、批量生产、验布、包装和出口协调

## 项目结构

- `client/`：React + Vite + Tailwind CSS 前端
- `server/`：Express、WebSocket、询价、商品、FAQ、文章和客服接口
- `server/data/`：本地面料、FAQ、文章和询价数据
- `client/public/fabric/`：面料视觉素材

## 本地运行

```bash
npm run dev:server
npm run dev
```

前端默认运行于 `http://127.0.0.1:5173`，后端默认运行于 `http://localhost:3001`。

## 构建

```bash
npm run build
```

构建过程包含 Vite 生产打包和公开页面 SEO 预渲染。

## 内容规范

产品信息使用面料行业字段：成分、克重、盎司、织物组织、可用门幅、弹力、颜色/色光、整理方式、MOQ、生产周期和建议用途。不得再使用成衣尺码段、版型梯度、单款件数或成衣系列作为核心商品字段。
